인프라 요청

새 환경 만들기

리소스 그룹 하나에 가상 네트워크, 가상 머신, PostgreSQL 데이터베이스, 웹 앱을 함께 만듭니다. 웹 앱은 가상 네트워크를 거쳐 데이터베이스에 연결되고, 데이터베이스는 인터넷에 노출되지 않습니다.

Azure 계정으로 로그인하면 요청을 보낼 수 있습니다. 리소스는 로그인한 계정의 권한으로 만들어집니다.

어디에 만들까요

없으면 새로 만듭니다.

이름과 크기

예: shop → shop-vnet, shop-vm, shop-web-…

가상 머신 접속

가상 머신에는 공인 IP가 없습니다. Azure Bastion이나 같은 네트워크 안에서 접속하세요.

데이터베이스 관리자

8자 이상, 대문자·소문자·숫자·기호 중 3종류 이상

완료까지 보통 10~20분 걸립니다.

배포 현황

요청을 보내면 리소스별 진행 상황이 여기에 표시됩니다.
